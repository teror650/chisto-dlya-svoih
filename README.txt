ЧИСТО ДЛЯ СВОИХ — PWA-пакет
Это устанавливаемая веб-версия, не APK-файл.
Чтобы установить на Android:
1. Разместите содержимое папки на HTTPS-хостинге (например, личном статическом хостинге).
2. Откройте адрес в Chrome на телефоне.
3. Меню Chrome → «Установить приложение» или «Добавить на главный экран».
После первой загрузки приложение кэшируется и работает офлайн.
